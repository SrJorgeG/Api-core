# Api-core

> Small REST API skeleton with Node.js, Express and Mongoose.

## What it does
Express app with a `/` route (GET user / POST user) handled by a controller and Mongoose models (`usuario`, `prueba`). Early learning project.

## Tech stack
JavaScript, Node.js, Express, MongoDB/Mongoose, ESLint (airbnb)

## Build & run
```bash
npm install
npm start   # nodemon app.js
```

## Structure
`app.js`, `server.js`, `routes/`, `controller/`, `models/`.
